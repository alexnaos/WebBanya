# WebBanya3 — Система управления баней на ESP8266

Прошивка для **Wemos D1 Mini (ESP8266)** для управления нагревом и мониторинга бани/отопления с веб-интерфейсом, MQTT (с Home Assistant) и OLED-дисплеем.

## 📋 Основные возможности

- **Датчики температуры:** до 8× DS18B20 на шине OneWire с **автоопределением** (автопоиск на старте, рескан каждые 30 с и по кнопке)
- **OLED дисплей:** 128×64 SSD1306 (I2C) — часы, статус, температуры
- **Часы реального времени:** DS3231 (I2C) с синхронизацией через веб-интерфейс
- **Управление нагрузкой:** ШИМ-регулировка мощности (D7, 10 кГц, 700–1023 — ниже 700 не опускается)
- **Веб-интерфейс:** GyverDB + SettingsGyver — настройка через браузер
- **MQTT + Home Assistant:** автоматическая интеграция через **MQTT Discovery**
- **Multi-WiFi:** Автоматическое переключение между двумя точками доступа
- **OTA:** Обновление прошивки по Wi-Fi
- **Автоматизация:** вся логика сценариев вынесена в Home Assistant (ESP только публикует состояние и исполняет команды)

## 🔧 Аппаратная часть

| Компонент       | Пин        | Примечание              |
|-----------------|------------|-------------------------|
| DS18B20 (data)  | D5 (GPIO14)| до 8 датчиков на одной шине (автоопределение) |
| OLED SSD1306    | I2C (D1, D2)| Адрес 0x3C              |
| DS3231 RTC      | I2C (D1, D2)| Часы реального времени  |
| MOSFET/SSR (PWM)| D7 (GPIO13)| 10 кГц, 10 бит (0–1023) |

## 📦 Зависимости (PlatformIO)

Все указаны в `platformio.ini`:
- `GyverDB` — база данных с автосохранением
- `Settings` — веб-интерфейс
- `OneWire` + `DallasTemperature` — датчики DS18B20
- `Adafruit GFX` + `Adafruit SSD1306` — OLED дисплей
- `GyverDS3231` — часы реального времени
- `ArduinoJson` — работа с JSON (MQTT)
- `PubSubClient` — MQTT

## 🚀 Быстрый старт

1. Установите [PlatformIO](https://platformio.org/) в VS Code
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/alexnaos/WebBanya.git
   cd WebBanya3
   ```
3. Отредактируйте `src/config.h`:
   - Настройте SSID и пароли Wi-Fi
   - Укажите адрес MQTT-сервера
   - Адреса DS18B20 задавать не нужно — датчики определяются автоматически
4. Соберите и загрузите прошивку:
   ```bash
   pio run --target upload           # Первая прошивка по USB
   pio run --target upload --upload-port "WebBanya3.local"  # OTA
   ```

## 🌐 Веб-интерфейс

После подключения к Wi-Fi откройте IP-адрес ESP в браузере.

Страница содержит:
- Отображение температур всех **автоопределённых** датчиков (группа «Температура»)
- Кнопка «Сканировать» — повторный поиск датчиков на шине
- Управление реле (вкл/выкл)
- Слайдер мощности (700–1023, шкала начинается с минимального рабочего ШИМ)
- Выбор режима
- Настройка даты/времени (синхронизация с RTC)
- Системные кнопки (reload, clear db)

### Кастомизация дизайна

Дизайн веб-интерфейса настраивается через файл `data/custom.js`, который загружается на LittleFS и подключается через хук `/custom.js` библиотеки [Settings](https://github.com/GyverLibs/Settings).

Формат файла — JavaScript-класс со статическим свойством `css`:
```javascript
class _ {
    static css = `
    /* ваши CSS-стили здесь */
    `;
}
```
Исходный код веб-приложения Settings: [Settings-web](https://github.com/GyverLibs/Settings-web).

**Как применить:**
1. Отредактировать `data/custom.js`
2. Загрузить на устройство через веб-интерфейс (☰ → файловый менеджер) или `pio run -t uploadfs`
3. Очистить кэш браузера и перезагрузить страницу

## 📡 MQTT

**Публикация** (JSON, каждые 2 сек):
- Топик: `esp/state`
- Поля (температуры): `temp1`…`tempN` — по числу найденных датчиков
- Служебные: `SensorCount`, `slider`, `toggle`, `select`, `select_mode`, `uptime`

**Управление** (подписка):
- `esp/set/slider` — мощность (число 700–1023, значения ниже 700 подрезаются до 700)
- `esp/set/toggle` — реле (`ON`/`OFF`)
- `esp/set/select` — режим (число или имя опции)

## 🏠 Home Assistant

Интеграция выполняется автоматически через **MQTT Discovery** — прошивка сама публикует конфигурацию сущностей при подключении к брокеру. Ручная настройка `configuration.yaml` не требуется.

### Что появится в HA

Устройство **WebBanya3** автоматически создаёт:

| Сущность | Тип | Описание |
|---|---|---|
| `sensor.webbanya3_tempN` | Температура | По одной сущности на каждый найденный датчик (`temp1`…`tempN`, имя «Температура датчик N») |
| `switch.webbanya3_relay` | Выключатель | Реле |
| `number.webbanya3_power` | Число (слайдер) | Мощность 700–1023 |
| `select.webbanya3_mode` | Выбор | Режим (var1/var2/hello) |

> Примечание: количество датчиков определяется автоматически. Если подключить/отключить DS18B20 и нажать **«Сканировать»** в веб-интерфейсе (или дождаться авторескана раз в 30 с), прошивка переотправит Discovery, и сущности `tempN` в HA обновятся.

### Карточка на дашборд

Пример карточки (используй сущности `tempN` по числу найденных датчиков):
```yaml
type: entities
title: WebBanya3
entities:
  - sensor.webbanya3_temp1
  - sensor.webbanya3_temp2
  - switch.webbanya3_relay
  - number.webbanya3_power
  - select.webbanya3_mode
```
1. HA → Обзор → ⋮ → Редактировать панель
2. + Добавить карточку → вкладка "Редактор кода"
3. Вставь содержимое выше → Сохранить

### Автоматизация

Вся логика сценариев (расписание, температура, дни недели) вынесена в Home Assistant.
Пример автоматизации:

```yaml
alias: "Баня: управление по температуре"
trigger:
  - platform: numeric_state
    entity_id: sensor.webbanya3_temp1
    below: 22
action:
  - service: switch.turn_on
    target:
      entity_id: switch.webbanya3_relay
  - service: number.set_value
    target:
      entity_id: number.webbanya3_power
    data:
      value: 512
```

## 🔧 Конфигурация

Все настройки в одном файле `src/config.h`:

| Макрос            | Значение     | Описание                     |
| ----------------- | ------------ | ---------------------------- |
| `WIFI_SSID_1`     | Ban2         | Основная точка доступа Wi-Fi |
| `WIFI_TIMEOUT_MS` | 15000        | Таймаут подключения (мс)     |
| `MQTT_SERVER`     | 192.168.1.23 | Адрес MQTT-брокера           |
| `TIMEZONE`        | 3            | Часовой пояс (МСК)           |
| `ONE_WIRE_BUS`    | D5           | Пин датчиков DS18B20         |
| `MAX_SENSORS`     | 8            | Макс. число датчиков DS18B20 |
| `TEMP_RESCAN_MS`  | 30000        | Период авторескана шины (мс) |
| `PWM_MAX`         | 1023         | Максимум ШИМ (10 бит)        |
| `MIN_FAN_PWM`     | 700          | Минимум ШИМ / нижняя граница ползунка мощности |
